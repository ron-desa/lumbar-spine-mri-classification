# Lumbar Spine Degeneration Classification from MRI

A deep learning pipeline for multi-task classification of lumbar spine degenerative conditions using MRI scans.

## Dataset

This project uses the RSNA Lumbar Spine Degenerative Classification dataset.

Due to size constraints, the dataset is not included.
You can download it from:
https://www.kaggle.com/competitions/rsna-2024-lumbar-spine-degenerative-classification
